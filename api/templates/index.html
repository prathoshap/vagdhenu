Vāgdhenu

Paste a Sanskrit verse in any Indic script → get a chanted MP3. Meter is auto-detected.
One shloka per chant · separate pādas with newlines or । / ॥
Advanced (optional)

REST API

POST /api/chant — JSON body {"text":"…","seed":60} → MP3 bytes
POST /api/chant/json — same body → JSON envelope with base64 MP3 + metadata
GET /api/meters — list of available meters
